# Komerce Design System

Welcome to the Komerce Design System. This design system provides a collection of reusable components, guided by clear standards, that can be assembled together to build any number of applications.

## Getting Started

This design system is built with React, TypeScript, and CSS Modules. It follows the Atomic Design methodology.

### Structure

- **Tokens**: Design variables (colors, typography, spacing, etc.)
- **Atoms**: Basic building blocks (Buttons, Inputs, Avatars)
- **Molecules**: Simple groups of UI elements working together (Breadcrumbs, Tabs)
- **Organisms**: Complex UI components (Table, Sidebar, Topbar)
